# Bia's Dream Kennel — React

Projeto Vite com dez páginas JSX, React Router, cabeçalho, rodapé, carrossel e livro de visitas em componentes. CSS original preservado em src/styles/original.css e estilos novos em react.css. Sem jQuery ou HTML injetado. O mapa é um link externo; o livro de visitas contém os comentários capturados, sem publicação local (backend não recuperável). Recursos ausentes no HAR e fontes externas podem não funcionar. 

## Executar

Node 18+; npm install; npm run dev. Para produção: npm run build. Configurar o alojamento para servir index.html nas rotas React.

A sintaxe JSX foi verificada; compilação e comparação visual não executadas.
